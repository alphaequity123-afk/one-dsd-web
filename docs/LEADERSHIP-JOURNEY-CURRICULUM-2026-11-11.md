# One DSD leadership program: architecture, curriculum, and program outline

November 11, 2026. Internal program and implementation guidance. This document is not staff-facing copy.

**Status.** Proposal for the owner's decision. No lesson, page, or tool described here has been written or built. "One DSD Leadership Journey" is a working title pending the owner's choice of name.

**Request.** Architect a leadership development program, with a curriculum and a program outline, in which equity and inclusion is the governing framework over conventional leadership development, consistent with One DHS and One DSD People, Access and Culture.

**Built on.** `LEADERSHIP-HUB-OUTLINE-2026-11-11.md` (analysis, standing rules, and decisions), `MMB-LEADERSHIP-PROGRAMS-RESEARCH-2026-11-11.md` (the State's framework), and `LEADERSHIP-PROGRAMS-SURVEY-2026-11-11.md` (other programs). The safeguards in the outline's section 3 apply to everything here and are not repeated.

**Audience and purpose, as set by the owner.** DSD staff identified with leadership potential, and new or experienced program leads, supervisors, managers (including deputy and assistant directors), and directors. The program equips them with advisory and practical knowledge, insight, and skill, professional and personal, to lead with an equity mindset and lens.

---

## 1. Architecture

### 1.1 The design idea

Most leadership programs teach a standard set of topics and add equity as one of them. This program does the reverse. It takes the standard topics from the State's own competency model and passes every one of them through the same equity frame. Equity is how each topic is taught, practiced, and reflected on. It is not a module.

### 1.2 Three layers

| Layer | What it is | Source |
| --- | --- | --- |
| **The frame (equity and inclusion)** | Five questions asked of every leadership topic, the IDI continuum as the direction of travel, and the State Equity Analysis Tool for decisions | The five shared learning focuses already in the application; the September 14 directive; the State of Minnesota Equity Analysis Tool |
| **The skeleton (leadership)** | The State's five leader competencies: Leading Self, Leading Others, Leading the Organization, Leading Outside the Organization, Getting Work Done | MMB Competency Definition Guide, March 2024 |
| **The setting (the work)** | Disability services, the employee life cycle, and the learner's own role | The 12 program profiles, 13 practice scenarios, and ten life-cycle stages already in the application |

### 1.3 The frame: five questions for every topic

These are the five shared learning focuses that One DHS and One DSD already use, restated for leaders. Using them keeps the leadership program inside the same learning design as the rest of the application.

| Focus | The question a leader asks | What it guards against |
| --- | --- | --- |
| **Curiosity** | What am I treating as the normal way, and where did I learn it? | Minimization: taking one's own default as neutral |
| **Perspectives** | Who is affected, whose experience is missing, and how would I find out? | Deciding for people without them |
| **Communication** | How do I adapt so that people can take part, and how will I check it worked? | Access offered in one form only |
| **Decisions** | Who decides, what evidence do we have, and what does an equity analysis show? | Good intentions without changed decisions |
| **Reflection** | What happened, for whom, and what will I keep, change, or stop? | Counting activity as results |

### 1.4 How a conventional topic is reworked

Every module follows the same method, so authors and learners can see the graft.

| Step | Example: delegation |
| --- | --- |
| 1. Take the conventional topic | Delegation: matching tasks to people and following up |
| 2. Name the State competency | Leading Others; Getting Work Done |
| 3. Ask the five questions | Who do I usually hand stretch work to, and why them? Who has never been offered it? How is the opportunity communicated? What criteria decide it? What happened after I changed it? |
| 4. Place it on the continuum | Minimization: "I give work to whoever is ready." Acceptance: noticing that readiness reflects who was given earlier chances. Adaptation: changing how opportunities are offered and supported |
| 5. Set it in DSD work | A life-cycle stage or practice scenario where the decision occurs |
| 6. Give an application | Make one opportunity visible with clear criteria and support; return to who took it up |

### 1.5 What the program borrows, and from where

| Element | Borrowed from | How it appears here |
| --- | --- | --- |
| Competency skeleton | MMB competency model | Every module is tagged to a State competency |
| Rings from self outward | MMB, OPM, NCWWI | The order of the five pathways |
| Separate tracks by role | NCWWI academies, state tiered programs | Five pathways, each with a new and an experienced set |
| Seven months, twice a month | MMB Emerging Leaders Institute | An optional pacing guide |
| Leader interviews, feedback, closing presentation | MMB Emerging Leaders Institute | A leader-interview guide, a feedback conversation guide, an optional closing summary |
| Equity before diversity and inclusion; begin with discovery | Center for Creative Leadership, REAL | Each pathway opens by examining the learner's own context |
| See, then engage, then act | National Equity Project | Curiosity and perspectives come before decisions in every module |
| Tie leadership to a result for a population | Annie E. Casey Foundation, Results Count | The reflection question and the evidence distinctions already in the application |
| Experience first, formal learning small | 70-20-10 | Short lessons; application in real work |
| Disability perspective | Minnesota Partners in Policymaking | Linked learning in the core and in pathways 2 and 5 |

## 2. Curriculum

### 2.1 Shape

- **A common core** of six modules, open to everyone and recommended first.
- **Five pathways** of six modules each, by scope of leadership work.
- Each pathway module has a **start here** lesson for someone new to that work and a **go further** lesson for someone experienced.
- Each module ends in an **application** the learner sizes to their own role, and a **reflection**.

That is 36 modules. Lessons run 10 to 20 minutes. Every lesson is written with three to five observable objectives, a calling-in approach, and a DSD example. The "learner can" column below gives the module's central outcome; the full objectives are written when each lesson is authored.

"Existing" names a resource already in the application that can anchor the module. "New" means the lesson has to be written. The existing-course matches come from a title and keyword scan and need confirming against the full inventory.

## 3. Program outline

### 3.1 How a learner moves through it

| Step | What happens | Notes |
| --- | --- | --- |
| Arrive | Choose a pathway by the work they do or want to do | No assessment, no nomination, nothing recorded |
| Core | Six core modules | Recommended first; not a gate |
| Pathway | Six modules, in any order | "Start here" or "go further" by the learner's own choice |
| Each module | Learn (10 to 20 minutes), reflect, apply in real work, capture, return | The same cycle throughout |
| Conversations | A peer, mentor, sponsor, leader interview, or Learning Lab | Optional; the learner arranges them |
| Close | A summary in the learner's own words; optionally shared with a supervisor or at a Learning Lab | Carries the training-credit notice. Not a certificate |
| Continue | Another pathway, a State program such as SEAL, ELI, or SLI, or a return to earlier modules | The program describes State programs as separate, with their own requirements |

### 3.2 Optional pacing

Two guides, both offered as suggestions:

- **Six-week cycle** for one module set: about 20 to 30 minutes of learning, 10 to 15 of reflection, and 45 to 90 of application each week.
- **Seven-month journey** in the rhythm of the Emerging Leaders Institute: two touchpoints a month, one shorter and one longer, covering the core and one pathway, ending with the closing summary.

### 3.3 What surrounds the curriculum

| Part | Form |
| --- | --- |
| Reflection journal | Six reflection types, saved on the learner's device, exportable |
| Application planner | Personal, project, and division sizes, with a self-review |
| Case library | The existing fictional DSD scenarios, viewed by leadership question |
| Conversation guides | Peer, mentor, sponsor, leader interview, feedback, learning from someone earlier in their career |
| Outside learning | Optional links to free courses listed in the survey, each checked before it is shown |
| ASK | Routes to pathway and module pages |

### 3.4 How the program would know it is useful

Evidence is about the program, never about a person: moderated task success on finding and using a pathway; voluntary participant accounts with their source and limits; recorded gaps and corrections. No completion counts by person, no rankings, no scores.

### 3.5 Order of work

1. Owner decisions (section 4).
2. Confirm existing-course matches against the full inventory.
3. Build the entry page, core, and five pathway pages from existing content.
4. Write the new "start here" lessons, core first.
5. Build the journal, planner, and export on the device.
6. Write the guides and the "go further" lessons.
7. Add ASK routing; verify each phase with tests, browser checks, and receipts.
